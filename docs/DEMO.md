# TrailQuest AI — demo guide

## Before recording

For the strongest demo, install Ollama and run `ollama pull qwen2.5:1.5b`, then start `python app.py`. Check that the footer says `LOCAL MODEL READY`. If model installation is not possible, record the sample-preview flow and clearly describe it as the UI preview—not as AI inference.

## 60–90 second walkthrough

1. **Show the problem (0–10 sec):** “A lot of apps keep us on-screen. TrailQuest uses a little AI to help someone decide what to do outside, then the screen can go away.”
2. **Set the mission (10–25 sec):** use `Guwahati, Assam`, select `Park`, `30 min`, and `Birds & wildlife`.
3. **Generate (25–45 sec):** click **Create my nature quest**. Point out the `LOCAL AI ACTIVE` status. Explain that the prompt goes to the model running on your computer, not to a paid hosted AI API.
4. **Use the checklist (45–60 sec):** mark one step complete, show the progress bar, then start and pause the timer.
5. **Take the phone outside (60–75 sec):** click **Take it with me** to copy the mission. Say that the goal is to spend the next 30 minutes noticing birds from a distance, not using the app.
6. **Explain open innovation (75–90 sec):** “The app, prompt, safety rules, and model choice can be inspected and changed. The local model makes privacy and model-swapping possible.”

## Suggested demo input

- Location: `Guwahati, Assam`
- Setting: `Park`
- Time: `30 min`
- Interest: `Birds & wildlife`
- Language: `English`
- Pace: `Gentle`
