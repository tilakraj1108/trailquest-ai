## TrailQuest AI 🌿 — a little less scroll, a little more wild

I built **TrailQuest AI**, a local-first outdoor mission generator. Choose a general area, setting, time budget, and interest—birds, plants, outdoor sounds, mindful observation, or nature photography—and it creates a short field checklist that gets you out into the real world. There is also a simple timer and a copy-to-go option so the phone can go back in your pocket.

### Why open innovation matters

TrailQuest uses **Qwen2.5 1.5B through Ollama** for local inference. After the model has been downloaded, mission generation can happen on the user's own computer without a paid hosted AI API. The app doesn't need an account or exact GPS location, and the prompt, guardrails, output validation, and UI are all inspectable and modifiable. The model can be swapped by changing one environment variable, so the community can experiment with different weights and languages.

The model is not just a label in the README: the running AI path calls the local Ollama chat endpoint. When a model isn't available, the interface clearly marks its output as a sample preview instead of pretending it's generated by AI.

### Try it

1. Run `python app.py` to open the sample preview at `http://127.0.0.1:8000`.
2. For local AI, install Ollama and run `ollama pull qwen2.5:1.5b`, then restart the app.
3. See `docs/DEMO.md` for a quick walkthrough.
